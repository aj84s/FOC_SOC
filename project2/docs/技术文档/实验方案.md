对，现在重新梳理后，实验逻辑清晰很多。之前引入速度环确实偏离了目标，你这个项目的核心不是“控制电机达到某个速度”，而是研究**固定驾驶意图下，电池SOC变化如何影响车辆动力表现**。

## 一、最终实验目标

模拟真实电动车骑行过程中的“固定油门”工况：

**油门给定 → 固定转矩需求(Iq_ref) → 电流环控制 → 电机输出转矩 → 测量实际转速变化**

通过实验获得：

1. 查表法SOC曲线：
   [
   SOC_{table}(t)
   ]

根据电池端电压查表得到，模拟低成本控制器方案。

2. 库仑积分SOC曲线：
   [
   SOC_{coulomb}(t)
   ]

根据INA226采集电流积分得到，作为传统工程方案。

3. 速度修正SOC曲线：
   [
   SOC_{speed}(t)
   ]

利用固定Iq条件下：

[
\frac{\Delta RPM}{\Delta SOC}
]

建立修正模型。

最终展示三条曲线，并证明速度信息可以改善低电量阶段SOC估计。

## 二、实验流程

### 实验1：建立SOC参考

条件：

* 3S 2200mAh电池；
* 完全充满；
* 固定放电工况。

采集：

* 电压；
* 电流；
* 时间。

通过INA226积分：

[
SOC_{ref}=1-\frac{\int I dt}{2200mAh}
]

得到参考曲线。

### 实验2：传统SOC算法对比

实时计算：

1. 电压查表SOC；
2. 普通库仑积分SOC。

比较：

[
SOC_{table}-SOC_{ref}
]

[
SOC_{coulomb}-SOC_{ref}
]

分析误差。

### 实验3：速度修正模型

保持：

* 固定Iq；
* 固定负载条件。

记录：

* RPM；
* SOC_ref。

分析：

[
K=\frac{\Delta RPM}{\Delta SOC}
]

建立：

SOC修正量=f(RPM变化)

得到第三条SOC曲线。

### 实验4：验证

换一组电池放电实验。

比较：

* 查表法误差；
* 库仑积分误差；
* 速度修正误差。

Iq_ref → 电流PI → Uq → PWM

这是实现“固定油门”的基础。

### 第二步：加入Hall测速

虽然Hall已经跑通，但需要整理成：

输入：
Hall边沿

输出：

RPM

用于后续：

[
\Delta RPM/\Delta SOC
]

### 第三步：INA226驱动

实现：

* 电池电压读取；
* 母线电流读取；
* 功率计算。

### 第四步：SOC算法模块

软件结构：

```
采集任务
 |

 |-- Current

 |
SOC算法

UART上传
```

### 第五步：实验数据分析

MATLAB/Python：

* SOC_ref
