## 一、霍尔编码器测速模块

### 1. 模块设计

- 新增 `encoder.c/h`（`MDK-ARM/user/encoder/`），基于TIM3霍尔传感器接口实现测速
- **硬件连接**：PC6（H1）、PC7（H2）、PC8（H3）→ TIM3_CH1/CH2/CH3
- **TIM3配置**：预分频169 → 1MHz计数，Period=65535，Slave RESET模式（每次霍尔跳变自动清零CNT）
- **霍尔状态映射**：GPIO IDR[8:6] 原始值 → hall_map[8] → 规范化状态1~6
- **方向判断**：通过 forward_next[7] 序列表比对前后两次霍尔状态，确定正转/反转
- **电角度估算**：6扇区对应固定电角度（0°/60°/120°/180°/240°/300°）→ hall_angle_rad[7] 查表
- **转速计算**：`RPM = 5,000,000 / Δcnt`
  - 推导：60 × 1MHz / (Δcnt × 每转12个霍尔边沿) = 5,000,000 / Δcnt

### 2. 代码结构

| 函数 | 功能 |
|------|------|
| `Encoder_Init()` | 清零结构体 → 读初始霍尔状态 → 启动HAL_TIMEx_HallSensor_Start_IT() |
| `Encoder_IC_Callback()` | 读CC1捕获值 → 查霍尔状态 → 判断方向 → 算RPM → 更新电角度 |
| `Encoder_GetSpeed()` | 返回当前转速 (RPM) |
| `Encoder_GetHallState()` | 返回当前霍尔状态 (1~6) |
| `Encoder_GetElectricalAngle()` | 返回估算电角度 (rad) |

## 二、FOC开环控制优化

### 1. TIM中断驱动

- FOC开环速度控制从主循环 `while(1)` 移到 TIM2 定时中断回调 `HAL_TIM_PeriodElapsedCallback()`
- TIM2 周期 = 0.1ms（10kHz），FOC函数内使用固定 `Ts = 0.0001f`，不再依赖 `HAL_GetTick()` 计时
- 控制频率稳定，避免了主循环执行时间抖动对角度积分的影响

### 2. 函数签名变更

- `FOC_velocityOpenLoop(float target_velocity, float Uq)` — 新增 Uq 参数，可外部传入
- `target_velocity` 单位改为 **rpm**（内部自动转换为 rad/s）
- 调用处：`FOC_velocityOpenLoop(1000, 2.0f)` — 目标1000rpm，Uq=2.0V

### 3. Bug修复

- 修正反Park变换参数顺序：`inversePark(Uq, Ud, angle_el, ...)` — 原来错误传为 `(Ud, Uq, ...)`

### 4. 串口速度监控

- 每1000次TIM2中断（≈1秒）printf输出一次：转速RPM、霍尔状态、方向
- 格式：`Speed: xxx.x RPM, Hall: x, Dir: x`

## 四、TIM配置变更

### 1. 新增 TIM3

- 霍尔传感器接口模式（`HAL_TIMEx_HallSensor_Init`）
- Slave Mode 配置为 RESET（每次TI1F_ED清零CNT，自动测量跳变间隔）
- GPIO：PC6/PC7/PC8，AF2_TIM3
- 中断优先级：1,0（次于TIM1，高于TIM2）

### 2. TIM1 调整

- 死区时间：1 → **10**（100ns → 1μs @170MHz），提高安全性
- 新增更新中断 `TIM1_UP_TIM16_IRQn`，优先级 0,0（最高）

### 3. TIM2 调整

- 中断优先级从 0,0 降为 2,0

### 4. 中断优先级分层

| 优先级 | 中断源 | 用途 |
|--------|--------|------|
| 0,0（最高）| TIM1_UP_TIM16 | PWM更新/刹车保护 |
| 1,0 | TIM3 | 霍尔传感器边沿捕获 |
| 2,0 | TIM2 | FOC控制周期 + 串口打印 |
| 3,0（最低）| USART2 | 串口收发 |
