## 一、INA226 电池监测

### 1. I2C 通信调试

- INA226 通过 I2C1 连接（SCL=PB6, SDA=PB7），地址 `0x40`
- **坑**：HAL I2C 的 `DevAddress` 需要 **7-bit 地址 << 1**，即 `0x80`
  - 写成 `0x40` 会导致 NACK，读回全 0x0000
- 上电后先读 Manufacturer ID（寄存器 0xFE → 预期 0x5449）验证通信正常

### 2. 驱动实现

| 函数 | 功能 |
|------|------|
| `INA226_WriteReg()` | HAL I2C1 写16位寄存器 |
| `INA226_ReadReg()` | HAL I2C1 读16位寄存器 |
| `BMS_INA226_Init()` | 读 Manuf ID → 写 Config (0x4527: 16avg, 1.1ms, 连续模式) |
| `BMS_ReadBusVoltage()` | 读总线电压 (mV), LSB=1.25mV |
| `BMS_ReadBusCurrent()` | 读分流电压 → 电流 (mA), Rshunt=0.1Ω |

### 3. 参数

- Config: 0x4527（16次平均、1.1ms转换时间、shunt+bus 连续模式）
- Rshunt = 0.1Ω
- 电流 LSB = 2.5μV / 0.1Ω = 0.025mA

## 二、三相电流采集（OPAMP + ADC + DMA）

### 1. 硬件链路

- **采样电阻**: 3mΩ 低端采样（每相下桥臂），量程 ±48A
- **运放**: OPAMP1/2/3 STANDALONE 模式，外部增益 10×（Rin=1k, Rf=10k）
- **偏置**: 1.65V（3.3V 经 20k+20k 分压）
- **ADC**: ADC1 CH3(U相)+CH12(W相), ADC2 CH3(V相), 12bit, TIM1_TRGO 触发
- **DMA**: 循环模式，半字传输，DMAContinuousRequests=ENABLE

### 2. 换算公式

```
I(A) = (Raw × 3.3/4095 - 1.65) / 0.03
```

### 3. 调试历程

| 现象 | 原因 | 解决 |
|------|------|------|
| 三相都 -55A | OPAMP 未启动 | `HAL_OPAMP_Start()` |
| 电流不更新 | `DMAContinuousRequests=DISABLE` | CubeMX 改为 ENABLE |
| 静止 2A 偏置 | 偏置电阻 ±1% 公差 | 零偏校准: 采100次取均值 |

### 4. 零偏校准 `Current_Calibrate()`

- 电机静止（TIM1 PWM 已启动但无电流），采 100 次 ADC 求均值
- 各相独立存储 `adc_zero[3]`，消除电阻公差引起的相间差异

### 5. 文件结构

- 新建 `MDK-ARM/user/foc/current.c` + `current.h`
- `Current_Init()` — 启动 OPAMP + ADC DMA
- `Current_ReadAll()` — 从 DMA buffer 读三相电流 (A)
- 打印速率: 100Hz (TIM2 每10次中断输出一次)

## 三、正 Clarke / 正 Park 变换

### 1. 背景

逆变换（`inversePark`/`inverseClarke`）在 foc.c 中已存在，用于将 Ud/Uq → 三相 PWM。需要正变换将三相电流 → Id/Iq，为电流闭环做准备。

### 2. 新增函数（foc.c）

```c
forwardClarke(Ia,Ib,Ic → Iα,Iβ)  // 等幅值: Iα=Ia, Iβ=(Ia+2Ib)/√3
forwardPark(Iα,Iβ,θ → Id,Iq)      // Id=Iα·cosθ+Iβ·sinθ, Iq=-Iα·sinθ+Iβ·cosθ
FOC_Current2DQ(Ia,Ib,Ic,θ → Id,Iq) // 一步完成
```

- 放在 foc.c 中，与已有逆变换配对
- 用 `sinf`/`cosf`（Cortex-M4F FPU，~14 周期/次）
- `electrical_angle` 通过 `extern` 从 foc.h 暴露

### 3. 串口输出格式

`rpm, Vbus(V), Ibus(A), Ia, Ib, Ic, Id, Iq` — 8列 CSV

### 4. 验证结果

- **未启动**: Id≈0, Iq≈0 ✓
- **500rpm 开环**: Id≈0~-1, Iq≈0~-2（Iq > Id，符合预期：q轴产生转矩）
- Ia/Ib/Ic 不是正弦波 → BLDC 梯形波反电动势，灌正弦电压必然畸变
- Id/Iq 不恒定 → 开环角度 ≠ 真实转子角度，闭环后会改善

## 四、电流环 PI 闭环

### 1. PI 控制器设计

- **为什么 P 和 I 都需要**: BEMF = ω×ψf 是持续扰动量，纯 P 永远有静差；I 累积抵消 BEMF 才能精确跟踪
- **抗饱和**: 条件积分（输出未饱和或误差反向时累加）+ 积分限幅

### 2. 新增（foc.c / foc.h）

```c
typedef struct { Kp, Ki, integral, output_max, output_min } PI_Controller_t;
PI_Init()   — 初始化 Kp/Ki/限幅
PI_Update() — 条件积分抗饱和
FOC_CurrentLoop(Iq_ref) — 读电流→Clarke/Park→PI(Id→0, Iq→Iq_ref)→PWM
```

### 3. 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `foc.voltage_power` | **11.5V** | 修正（原24.0V，实际供电11.5V） |
| `target_iq` | 0.3A | 初始值，可通过串口修改 |
| pi_id | Kp=0.5, Ki=10, ±5.7V | Id→0 |
| pi_iq | Kp=1.0, Ki=50, ±5.7V | Iq→Iq_ref |
| 电角度 | 开环积分 | 仍用 target_rpm 积分（非编码器） |

### 4. 控制链路

```
Iq_ref → [PIq] → Uq ─→ [逆Park+逆Clarke+PWM] → 电机
0       → [PId] → Ud ─┘                    ↑
                                            │
         Ia,Ib,Ic ← [正Clarke+正Park] ←─────┘
                   ↑
              electrical_angle (开环积分)
```

### 5. 安全保护

- 输出限幅 ±5.7V（Vbus/2），防止过调制
- 积分限幅 + 条件积分抗饱和
- 停机时清零 PI 积分，防止下次启动瞬态冲击
- 电机未启动（motor_enable=0）不跑电流环
